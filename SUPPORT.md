### Questions and Discussions

For general questions, feature requests, or discussions:

1. **Check Existing Issues**: Search
   [existing issues](https://github.com/scape-agency/rite/issues)
   to see if your question has been answered
2. **GitHub Discussions**: Start a
   [discussion](https://github.com/scape-agency/rite/discussions)
   for questions and ideas
3. **Stack Overflow**: Tag questions with `rite` and `python`

### Bug Reports

If you've found a bug, please
[open an issue](https://github.com/scape-agency/rite/issues/new)
with:

-   Clear description of the issue
-   Steps to reproduce
-   Expected vs actual behavior
-   Python version and OS
-   Minimal code example

See our
[Contributing Guide](CONTRIBUTING.md#reporting-bugs)
for details.

### Feature Requests

We welcome feature requests! Please:

1. Check if the feature already exists or is planned
2. [Open a feature request](https://github.com/scape-agency/rite/issues/new?labels=feature)
3. Describe the use case and benefits
4. Provide example usage if possible

### Security Issues

**Do not open public issues for security vulnerabilities.**

Please email security concerns to: **security@scape.agency**

See our [Security Policy](SECURITY.md) for details.
